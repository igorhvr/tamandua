# Junk Files

This project contains deliberately untracked junk files used as probes for
the tamandua torture test suite.

## Files

- **`operator-notes.local`** — Inert operator junk. Must never be touched by
  any tool. Byte-identical to fixture source (provisioning) reference throughout the
  campaign.
- **`package-lock.json`** — Regenerated by `npm install`. Deliberately not
  gitignored. Serves as a dirty-tree regression signal.
- **`node_modules/`** — Contains a stray file generated during test runs.
  Deliberately not gitignored. Oracles verify untracked presence of
  regenerated junk.

## DO NOT

- `git add` these files
- Add them to `.gitignore`
- Clean them up with any tool or script
- Delete `operator-notes.local`

These files are load-bearing signals for dirty-tree regression detection.
