# tt-poly — Five-Language Storm Monorepo Fixture

A tamandua torture-test fixture that combines five language subtrees into a
single monorepo. Used by the Tier-2 storm (spec 09 — wave 5) and provides
the full five-language defect surface for the composite `seed/storm` ref.

## TEST_CMD

```bash
./run-all-tests
```

Expect ~6–10 minutes wall time with all five suites bootstrapped.

## Requirements

- **python3** on PATH (python3 or python)
- **node** (≥ 22) on PATH
- **go** on PATH (go test)
- **Rust toolchain** (cargo on PATH via nix or rustup)
- **Java JDK** (java not on PATH — must be discoverable via JAVA_HOME env var)
- No network access required after initial dotfile downloads

## Junk Probes

This fixture carries **intentional untracked junk** per spec 02's two-class
junk-probe requirement. Neither class is gitignored — oracles verify they
appear as untracked in `git status` so the dirty-tree gate tolerates them
while rejecting tracked drift.

| Artifact | Class | Location | Notes |
|---|---|---|---|
| `__pycache__/` | Regenerated | python/src/schedlib/, python/tests/ | Python bytecode cache |
| `.pytest_cache/` | Regenerated | python/ | pytest cache (`.gitignore` removed at end of each run) |
| `.flaky_counter` | Regenerated | python/ | Counter file for POLY-FLAKY-P1 alternator |
| `package-lock.json` | Regenerated | ts/ | Generated by npm install |
| `node_modules/` | Regenerated | ts/ | Contains `.tamandua-stray-probe.txt` after pretest |
| `target/` | Regenerated | java/ | Maven build output |
| `target/` | Regenerated | rust/ | Cargo build output (huge) |
| `operator-notes.local` | Inert | root, python/, ts/, go/, rust/, java/ | Fixed byte-content, never touched |

See `JUNK-IS-INTENTIONAL.md` and `README-JUNK.md` for detailed
documentation on each probe.

## Integrity Invariants

1. **Baseline green:** `./run-all-tests` exits 0 on the pristine tree
2. **Seed isolation:** each seed applies cleanly to baseline
3. **Fix correctness:** each fix patch restores green when applied on
   top of its seed
4. **Junk presence:** all junk probes exist and are untracked after one
   full test run
5. **Inert junk integrity:** every `operator-notes.local` is byte-identical
   to the committed sampler
6. **Deterministic builds:** two consecutive runs of `build-golden.sh`
   produce identical commit hashes
