## What changed — `torture-test/bin/daemon-control`

1. **Per-worktree systemd scope unit name** (mirrors the T2.1 US-009 pattern
   prototyped in worktree 865):
   - New helper `scope_suffix_for_root()` derives a stable 8-hex suffix from
     `TT_REPO_ROOT` (`cksum`), and `cmd_start` builds
     `tamandua-tt-<kind>-<suffix>` — e.g. for this worktree
     `tamandua-tt-scripted-73fb6661`.
   - The OLD fixed name `tamandua-tt-<kind>` was shared by every worktree, so
     a concurrent run's `cmd_start` pre-launch `systemctl stop` (or `cmd_stop`
     cleanup) TERM'd another run's in-flight `systemd-run` daemon launch (the
     E3.C.2 scripted-start SIGTERM regression: bash prints `Terminated <cmd>`,
     `set -e` exits 143, `run-scripted-scenario:285` reports failure).
   - Used consistently at: `cmd_start`'s `systemd-run --unit` + pre-launch
     `stop`/`reset-failed`, provenance `scopeUnit`, `verify_cgroup`, and
     `cmd_stop`'s cleanup paths (via the recorded provenance scope).
   - The `tamandua-tt-` prefix is preserved so `daemon-control.test.sh`
     Test 18 (prefix match) still passes.

2. **Cross-worktree stop isolation in `cmd_stop`** (new `scope_unit_is_ours()`
   gate): both the idempotent "already stopped" residual-scope cleanup and
   Step 5 scope cleanup now refuse to `systemctl --user stop` any recorded
   scope that is NOT this worktree's derived unit. A legacy provenance record
   naming the bare fixed scope (or a foreign worktree's unit) is REFUSED,
   never stopped — stopping it would TERM another run's daemon.

3. **Bounded port-free wait before launch** (`TT_DAEMON_PORT_WAIT_SECONDS`,
   default **10s** — small so self-tests stay fast; overridable): `cmd_start`
   waits for the kind's fixed ports (scripted 5334/5338/5339, real
   4334/4338/4339) to be free BEFORE launching, so concurrent worktrees
   serialize on the shared ports instead of EADDRINUSE-failing their
   bootstrap. Requires the ports free STABLY (two observations across a 2s
   settle) and fails with a clear diagnostic (`refusing to launch into a busy
   port`) if the bound is exceeded.

4. **Stale `tamandua.pid` cleanup**: a pid file whose pid is dead/empty
   (left by a killed daemon) is removed before the launch so the pid wait
   observes the NEW daemon's pid file.

## Why E3.C.1's own bare-tier1 GREEN x2 proof passed anyway (root cause, US-001)

The collision is a RACE that only manifests on destructive interleaving of the
fixed scope name/ports across concurrent worktrees. The E3.C.1 proof protocol
had NO concurrent-run isolation guard, so its two bare-tier1 runs simply did
not destructively interleave with the concurrent 865/866 campaigns that were
driving the same fixed scope/ports at that time — a proof-protocol gap.
US-003 adds the permanent regression guard
(`self-tests/tier1-daemon-control-scope-isolation.test.ts`).
