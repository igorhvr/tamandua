# E3.C: implement lifecycle probe sequences, chaos injection, and the O16/O4 oracles

Campaign #7's biggest discovery (bd `tier1-suite-defect-backlog` S3, S4):
the five lifecycle cases and the chaos marathon never ran their probes —
`tt-controller` only does launch→wait→(cap-stop)→snapshot, `tt-chaos` is
never invoked, and oracles O16/O4 are declared in manifests but have no
executables. ~2.6M tokens bought zero lifecycle coverage. Build the
machinery per spec (07-wave-3 + 12-runner-automation + 03-oracles):

1. **Probe sequencer** in the controller's real-case arm: a per-case
   `probe_sequence` (manifest-declared, schema'd in case.schema.json)
   the controller executes against the CONTAINED TT instance (43xx CLI,
   contained env) while the case's run(s) are in flight:
   - W3.18: pause (no drain) mid-run → hold 10m → resume → run must
     complete; W3.19: pause --drain variant;
   - W3.20: TWO runs — cancel mid-implement; cancel during
     finalize_merge (assert `run.canceled` terminal event lands — CNEV
     is now in the product, the case must assert it);
   - W3.21: fail --force mid-run → resume → SAME run id resumes (the
     resumeWorkflow-reuses-run-id trap) → completes;
   - W3.22: three concurrent runs + contained-daemon restart mid-flight
     → all three recover within 2 dispatch intervals, token flush
     preserved (DC8);
   Every probe action + observed effect goes into attempt evidence
   (timestamps, CLI exit codes, event-stream excerpts).
2. **Chaos wiring**: the controller must honor manifest `chaos` blocks
   by invoking `bin/tt-chaos` (sigstop_sigcont on the harness process,
   trigger/hold per manifest) with start/stop records in evidence and
   chaos.log; W3.17b must genuinely differ from W3.17a.
3. **O16 lifecycle oracle** (new executable, CONTRACT.md entry): judges
   probe evidence — pause held (no rounds dispatched during hold),
   drain semantics, cancel terminal events, resume same-run-id,
   restart recovery windows. **O4** (declared in W3.0x manifests):
   implement per spec 03 or, if spec marks it out of Tier-1 scope,
   remove it from the manifests with a documented decision — no
   declared-but-missing oracles may remain.
4. Wall caps for the five lifecycle cases resized to fit their probe
   sequences (hold times + run time + margin), consistent with E3.D's
   cap table.
5. Prove ZERO-token: scripted daemon + scripted harness dry-runs of
   every probe sequence (the 53xx scripted instance exists for exactly
   this) — each sequence exercised end-to-end with evidence + O16
   verdicts on scripted fixtures; bare `./run-torture-test --tier1`
   GREEN x2; hygiene clean; no leaked daemons (43xx/53xx down after).
6. Self-tests for the sequencer (fail-closed on unknown probe verbs,
   probe CLI failures → TEST_INFRA_FAIL with distinct reasons).
