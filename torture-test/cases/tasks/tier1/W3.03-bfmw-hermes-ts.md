### BUG SYMPTOM (red-herring archetype)

Users report that exporting expenses to CSV produces files where category names are truncated by one character in the last row. For example, a category named "Groceries" appears as "Grocerie" — but only for the final row in the export.

The natural place to look is the CSV serialization in `src/expense/export.ts`, but the actual root cause is a buffer-offset error in `src/util/io.ts` — the file-write helper reads one byte short of the full buffer when the buffer size isn't page-aligned, which the CSV export triggers because its trailing newline padding creates an unaligned final write. Fixing the CSV formatter will silence one symptom but leave the root cause and corrupt any other non-page-aligned writes.

**This is a red-herring:** the symptom points at `export.ts`, but the defect is in `io.ts`. You must investigate past the obvious target. Hermes' longer round and retry chain makes the investigation depth requirement realistic.
