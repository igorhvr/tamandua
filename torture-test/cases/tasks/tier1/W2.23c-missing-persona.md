# W2.23c: Hostile custom workflow — missing persona file

Scripted scenario (~0 tokens) testing workflow validation: install a custom workflow whose agent workspace references a baseDir that exists but is missing required persona files (e.g., no AGENTS.md), then attempt to run it.

## Task

1. Install a purpose-built hostile custom workflow whose agent workspace has a `baseDir` directory that exists but contains no AGENTS.md (the persona files are silently absent)
2. Launch `tamandua workflow run <hostile-workflow-id> "test task"`
3. Assert the outcome: if current behavior silently skips missing persona files at provision time, the run will likely fail mid-execution when the agent has no instructions — document this as a PRODUCT_FAIL candidate
4. Assert that the daemon does not crash, and the failure is surfaced (either at install time as a warning, or at run time as a step failure with a clear diagnostic)

## Boundaries

- This is a scripted (~0 token) scenario running under the hermetic scenario harness
- Never touch the live daemon (33xx ports)
- The hostile workflow is isolated to the scenario's temp state dir
