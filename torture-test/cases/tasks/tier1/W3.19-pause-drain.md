Real hermes run: feature-dev-merge-worktree on tt-ts. This lifecycle probe tests pause-with-drain while an implement story is claimed and running. Drain must let the in-flight story's step complete, then park WITHOUT dispatching the next story — never produce a draining_pause wedge (empty-loop-state fossil). Resume dispatches the next story.

### Feature: Expense Statistics Summary

Add aggregate statistics to the expense tracker.

**Acceptance Criteria:**
1. `src/expense/calculator.ts`: add `getStats()` returning `{ total, average, min, max, count }` across all expenses
2. Support optional category filter: `getStats({ category?: string })` returns stats scoped to that category
3. `src/expense/export.ts`: add a `--stats` flag to the CSV export that prepends a statistics summary section
4. Tests for the stats calculation and the export integration

## Boundaries

- Work within `src/expense/` and test files
- Do not modify `operator-notes.local` or files under `seeds/` or `probes/`
- This is sized for 2-3 stories so the drain can operate between stories
