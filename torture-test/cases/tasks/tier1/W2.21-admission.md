# W2.21: Admission edge — daemon-stopped dispatch

Scripted scenario validating admission-edge behavior: launch a just-do-it workflow run with the TT daemon stopped and assert the reconciler admits it within one dispatch interval of daemon start.

## Task

1. Start with the TT daemon stopped
2. Launch `tamandua workflow run just-do-it --task-file <task>` with daemon down
3. Assert exactly one run row is created with pending-admission state
4. Assert the CLI output is success-shaped (no crash, no hang)
5. Assert `tamandua workflow nudge` with daemon down exits non-zero and spawns nothing
6. Start the daemon
7. Assert the reconciler admits the run within one dispatch interval
8. Assert the run reaches terminal state through the scripted harness

## Boundaries

- This is a scripted (~0 token) scenario running under the hermetic scenario harness
- Never touch the live daemon (33xx ports)
- All operations use the daemon-control scripted wrapper
