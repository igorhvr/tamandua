# W3.22: Lifecycle Probe — Daemon restart under load

Real pi runs: 3 concurrent fdmw runs on tt-ts. This lifecycle probe tests `tamandua restart` while runs are mid-flight.

**Probe sequence:** The controller launches 3 fdmw runs against tt-ts with staggered starts. While at least one run has an active story, issue `tamandua restart`. Assertions: grace-preserving teardown (token flush survives — DC8); all 3 runs progress within 2 dispatch intervals; no wedge, no double dispatch; status truthful throughout.

### Tasks (one per run)

**Run 1 — Expense Category Management:**
1. Add a `categories.ts` module with `addCategory(name, budget?)`, `removeCategory(name)`, `listCategories()`
2. Integration: expenses must reference existing categories
3. Tests for CRUD operations and referential integrity

**Run 2 — Expense Validation Rules:**
1. Add a `validation.ts` module with `validateExpense(expense)` returning `{ valid, errors[] }`
2. Rules: amount > 0, category non-empty, date valid ISO-8601 parseable
3. Tests for each rule and combined validation

**Run 3 — Expense Search API:**
1. Add a `search.ts` module with `searchExpenses(query)` supporting substring match on description and category
2. Case-insensitive matching
3. Tests for match/no-match, case insensitivity, empty query

## Boundaries

- Work within `src/expense/` and test files
- Do not modify `operator-notes.local` or files under `seeds/` or `probes/`
- Each run implements ONE of the three tasks above
