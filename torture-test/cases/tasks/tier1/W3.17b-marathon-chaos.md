## Task

Implement the following cross-language feature on the tt-poly-lite fixture.

### Feature: Unified Configuration Validation

Add a declarative configuration validator that works identically in both the Python (`python/`) and TypeScript (`ts/`) subtrees of tt-poly-lite.

**Acceptance Criteria:**
1. Python subtree: add `python/configval/` module with a schema-driven validator supporting required fields, type checking (str/int/bool/list), and nested objects
2. TypeScript subtree: add `ts/src/configval/` module with the same schema-driven validator API, accepting the same schema format
3. Both implementations accept identical JSON schema definitions and produce identical validation error messages for the same inputs
4. Each subtree includes a `config.schema.json` example and tests that validate the validator against it
5. Cross-language conformity test: a script under `run-all-tests` validates that both implementations produce byte-identical output for a shared test corpus of configs and schemas

**Chaos injection is active:** tt-chaos will SIGSTOP the hermes process mid-round, hold it past the 90min coding round timeout, then SIGCONT. Assertions: the round is terminated ONCE, attributed, and retried with `timeout_retry` context — never double-dispatched into the same workdir; recovery attribution names the harness round timeout mechanism, not abandoned-step or stale-claim; no watchdog kill of any live round below the wall (O4); the run completes or fails honestly.
