# W1.L1-ts: Wave-1 Language Smoke — do-now pi on tt-ts

Add one small pure function + its unit test to the tt-ts fixture (Expense Tracker).

## Task

1. Clone or enter the tt-ts fixture repository
2. Add a small, well-defined pure function to an appropriate module — for example, an `averageExpense(expenses)` helper function that computes the average amount from an array of expense objects.
3. Write a corresponding unit test for that function
4. Run the full test suite using the declared TEST_CMD to confirm all tests (including yours) pass
5. Commit: `feat: add utility function with test`

## Setup

This is a do-now (setup-free) workflow — the harness provisions the fixture.

## Boundaries

- Stay within `src/` and corresponding test files
- Do not modify existing source files
- Do not touch `operator-notes.local`, `seeds/`, or any files under `probes/`
- Keep additions small and focused — this is a language smoke test, not a feature
