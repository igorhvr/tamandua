## Provisioning (hostile path mechanism)

The harness provisions your working clone at a path that contains a space and a non-ASCII character: the case's fixture value is the reserved hostile-path alias `tt-ts café` (U+0020 space + é U+00E9), and the provisioner creates the work clone directory under that exact name (e.g. `<work-dir>/W1.X1-ts/tt-ts café`). The alias resolves to the canonical tt-ts fixture for the golden tree, so the clone content is ordinary tt-ts.

You MUST work from that provisioned clone — the path with the space and the `é` IS the probe. Do not move or re-clone the repository to a "clean" path; all git operations, tests, and file edits must happen inside the hostile path.
