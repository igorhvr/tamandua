# W1.L1-python: Wave-1 Language Smoke — do-now pi on tt-python

Add one small pure function + its unit test to the tt-python fixture (schedlib library).

## Task

1. Clone or enter the tt-python fixture repository
2. Add a small, well-defined pure function to an appropriate module in `src/schedlib/` — for example, a `days_between(start, end)` function that returns the number of calendar days between two dates.
3. Write a corresponding unit test for that function under `tests/`
4. Run the full test suite using the declared TEST_CMD to confirm all tests (including yours) pass
5. Commit: `feat: add utility function with test`

## Setup

This is a do-now (setup-free) workflow — the harness provisions the fixture. tt-python uses pytest with a venv; the bootstrap should handle environment setup.

## Boundaries

- Stay within `src/schedlib/` and `tests/`
- Do not modify existing source files
- Do not touch `operator-notes.local`, `seeds/`, or any files under `probes/`
- Keep additions small and focused — this is a language smoke test, not a feature
