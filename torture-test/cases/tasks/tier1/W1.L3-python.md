# W1.L3-python: Wave-1 Language Smoke — bug-fix direct mode on tt-python

## Symptom

The existing test suite does not cover the count+until combination — you must write the regression test to surface the bug, then fix it.

3. Write a regression test that exercises the count+until combination and fails on the buggy code
4. Verify the fix and the regression test pass
5. Commit with a clear message
