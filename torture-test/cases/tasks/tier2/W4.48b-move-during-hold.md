## Premise the cell pins

Spec 08 §G W4.48 arm (b) — the composed-fault corridor: `workflow pause`
issued between target-moved detection and the relaunch decision must produce
EXACTLY ONE of {relaunch, paused-no-relaunch}; never a relaunch that starts
paused-orphaned; never a double relaunch on resume. The former real
`W4.48b-pause-rugpull-window` cell armed its pause on `event:merge.target_moved`
and raced the chaos cadence to land a move inside the detection→relaunch
window — the race never fired in real campaigns (S29/S37/mac #1).

**This cell exercises the pause/relaunch VECTOR without relying on that race:
it CONSTRUCTS the moved-target state deterministically — pause the run FIRST
at a step marker (the hold), then move the target WHILE the run is held (the
move-target-during-hold seam), then resume.** The pause cannot race the move:
the hold is already in place when the move lands, so the resumed finalize
GUARANTEEDLY observes a moved tip.

## Injection / deterministic choreography (no race)

The corridor is constructed from TWO deterministic declarations (no timing
dependence between them):

1. **`pause` armed on `step:finalize_merge:running` (hold 600s)** — the probe
   pauses the run at the first finalize dispatch. From that moment the run is
   in a deterministic HOLD (no further rounds dispatch).
2. **Typed `move-branch` chaos (free-running cadence) armed on the SAME
   `step:finalize_merge:running` marker** — the chaos loop is an external
   process that keeps moving the target every `interval_s` until its budget is
   spent or the run is terminal. A PAUSED run is not terminal, so the moves
   land DURING the hold — the target is guaranteed moved (≥ 1 parent back)
   before the hold ends. (`repeat: 5, interval_s: 30` vs the 600s hold: every
   post-arm move fires inside the hold.)
3. **`resume` armed on `now`** — fires as the hold ends. The resumed finalize
   captures the (moved) tip and the merger/relaunch machinery makes its
   decision against the moved target.

The scripted merger is a plain `done` behavior (a single honest landing
attempt): the moved-target state the decision machinery observes comes from
the pause-hold construction, never from a scripted retry storm.
