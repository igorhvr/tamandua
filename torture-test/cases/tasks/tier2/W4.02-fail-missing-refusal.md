## Seeded defect (BUG-T2 — what the fixture actually contains)

The tt-ts fixture's seed `BUG-T2` (SEEDS.md catalog) implants an **A2 two-module
date-handling bug**: `src/server.ts` parses user-provided dates from POST body
with `new Date(dateStr).toISOString()`, producing full ISO datetime strings
with timezone offsets, while `src/store.ts` `getByDateRange` uses naive string
comparison (`localeCompare`). When a full ISO string like
`2025-06-15T15:00:00.000Z` is compared against a YYYY-MM-DD query, the `T`
sorts after end-of-string and the expense is excluded from exact-date queries.
Both files must be fixed (server normalizes to UTC midnight; store compares UTC
timestamps). The fixer's regression tests cover the POST-normalization and
date-range filtering paths.

## Injection (same drain barrier as W4.01)

1. `workflow pause --drain` fires while `verify` is still running

   promoted to pending.

machinery resolves it to the run's attested `TESTED_TREE` before arming
tt-chaos.
