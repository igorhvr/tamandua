# W4.19: Artificially stale catalog stamp — warn-not-block (scripted, zero tokens; gating)

Scripted local-command case (zero tokens): the scenario cell
`scenarios/w4.19/stale-catalog-warn-not-block/` writes an ARTIFICIALLY
stale `.catalog-version.json` stamp into the contained scripted daemon's
workflows dir (spec 08 §E W4.19 — "Artificially stale catalog stamp;
launch"), then launches a real `workflow run` (scripted-pi harness, zero
tokens) and runs `tamandua doctor`.

## What the scenario actually exercises (per spec)

- The harness's `workflow install do-now` writes a CURRENT catalog stamp
  (`~/.tamandua/workflows/.catalog-version.json` with the build version).
  The cell OVERWRITES it with a stale version
  (`20200101T000000Z_artificially-stale` — the injection under test).
- **Launch (warn-not-block):** `workflow run <scenario workflow copy> ... --wait
  --json` (the copy id `TT_SCENARIO_WORKFLOW_ID` — the harness-installed
  workflow whose agent key exists in the materialized behaviors, so the
  scripted-pi runtime completes the step with zero tokens) must PROCEED and
  complete while `stderr` carries the ONE-LINE launch warning "Warning:
  installed catalog is older than bundled catalog. Run tamandua update
  --force to apply latest workflow/persona fixes." — the stale stamp never
  blocks a launch.
- **Doctor STALENESS flag:** `tamandua doctor` must surface the STALENESS
  group's "Installed catalog vs bundled catalog" check with "is older than
  bundled catalog version" + the "tamandua update --force" remedy — and
  still exit 0 (the stale stamp is a WARN, never a fail/block).

## Expected

- The scenario cell runs PASS (exit 0) with `caps.tokens = 0` — zero
  tokens, no real pi/hermes/dsh invocation.
- The launch warning fires exactly once and the run completes
  (status `completed`).
- doctor exits 0 with the STALENESS flag naming the stale stamp and the
  force-update remedy.
- The contained scripted daemon is left stopped; ports 5334/5338/5339 free.

## Boundaries

  state dir and the scratch workdir under `torture-test/var/`;

- The tier0 w4.49 cells remain the reference shape; this cell is NEW (never
